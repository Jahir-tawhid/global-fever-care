# 🌍 Global FeverCare

**Global FeverCare** is a modern React & Vite based web application that assesses a user's basic physical condition based on body temperature, age, and symptoms, providing local brand medicine recommendations and accurate dosages across 10 different countries.

---

## 🚀 Key Features

- **Multi-Country Support:** Includes local brand medicine databases for Bangladesh, Pakistan, Saudi Arabia, USA, UK, Qatar, UAE, Kuwait, China, and India.
- **Symptom Checker:** Evaluates mild, severe, or normal fever conditions based on body temperature (°F) and the patient's age.
- **Smart Dosage System:** Provides tailored and accurate dosage instructions customized for children, adult males, and adult females.
- **Health Conditions Filtering:** Offers custom warnings and gastric medicine suggestions for specific pre-existing health conditions such as diabetes, heart disease, pregnancy, and acidity.
- **Random Medicine Picker:** Automatically selects a randomized, effective medicine when multiple options are available in a category.

---

## 🛠️ Tech Stack
